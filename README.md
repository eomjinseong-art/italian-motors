# 이탈리아차 컬렉션 아카이브

Italian Motors. 클래식부터 현재까지 이탈리아 자동차 브랜드와 모델을 모은 한국어 카탈로그입니다.

비공식 팬사이트이며 제조사와 제휴하지 않습니다. 상표는 각 권리자의 소유입니다.

- 라이브 예정 주소: https://italian-motors.vercel.app
- 자매 아카이브: https://british-motors.vercel.app · https://usa-motors.vercel.app
- 사진: 위키미디어 공용 중 상용 이용이 허용된 라이선스만 (`npm run fetch-images`)
- 방문 수: Abacus `italian-motors` / `visits`
- 자동차용품: 오토픽스 (`car-parts-cpang`)
